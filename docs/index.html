How it works

01

Run once before bed

Just python3 sloth_box.py run --apply. No paths to configure. It auto-discovers Downloads, Desktop, Documents, Screenshots.

02

Gemma organizes overnight

Open-weight Gemma 3 runs locally via Ollama at os.nice(19) — idle CPU. Renames, categorizes, extracts deadlines. All on your device.

03

Find anything by memory

Open 127.0.0.1:8765. Search "paneer recipe september" or "rent chat rahul". SQLite FTS5 + BM25 ranking finds it instantly.

Get started

# Requires Python 3.9+ and Ollama with gemma3:4b
# Works WITHOUT Ollama too (rule-based fallback mode)

git clone https://github.com/chourasiavinit9-dev/findbox
cd findbox

# Dry-run first (safe — nothing moves)
python3 sloth_box.py run

# Execute moves when happy with the plan
python3 sloth_box.py run --apply

# Launch search UI at http://127.0.0.1:8765
python3 sloth_box.py serve

# Undo everything if needed
python3 sloth_box.py undo

Why findbox

🌍

Zero-Config Auto-Scan

No paths. Just run it. Automatically finds Downloads, Desktop, Documents, Screenshots, WhatsApp Chat exports, iCloud Drive — every digital landfill on your device.

🔒

100% Private by Design

Your OTPs, bank statements, Aadhaar scans, and private chats never leave your device. Open-weight Gemma runs entirely in local RAM. Zero cloud, works on airplanes.

🧠

Vague Memory Search

Can't remember the filename? Search "paneer recipe september" → AI parses it into keywords + category + date range → SQLite FTS5 BM25 ranking finds the exact file.

🛡️

Truly Safe by Default

Dry-run by default. Atomic undo. No overwrites (collision suffixes). Never deletes. Executable quarantine (ELF, PE, Mach-O detected by magic bytes). XSS-immune UI.
